# Hito 0 · Vuelta al taller

**.venv:** un entorno virtual. Una despensa privada con las librerías de este proyecto, para poder trastear sin contaminar al resto.

**.gitignore:** la lista de cosas que Git no debe guardar ni subir: lo que se puede recrear (.venv), lo temporal (cachés), lo secreto (claves) y los resultados (CSV). Versiono la receta, no el plato.

**Sangría:** dice de quién cuelga cada línea. Si cambia la sangría, cambia a qué bloque pertenece. Al leer código me pregunto: "¿de quién cuelga esta línea?".

**try / except:** `try` intenta algo; si falla con un error concreto, `except` lo recoge y hace otra cosa en lugar de estrellar el programa.

**while / continue / break:** `while True` repite siempre. `continue` vuelve al principio de la vuelta (pregunta otra vez); `break` sale del bucle (la fecha era buena).

**Git:** `status` (qué ha cambiado), `add` (preparo), `commit` (foto), `push` (subo). `git remote -v` me dice a qué GitHub está conectado el repo.
